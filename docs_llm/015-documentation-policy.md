## 005 · Identity and pairing

Block ID: **GFL-015-005**.

Follow constitution section 9 and GC-005. Use GFL identities, three-digit filenames spaced by five and matching paths/IDs/anchors in both views. Preserve identities across moves, fix links and never reuse retired IDs.

<a id="gfl-015-010"></a>

## 010 · Presentation and publication

Block ID: **GFL-015-010**.

Use the default classic `sphinx_rtd_theme`, Gramlot logo and scaffold notice. Public docs follow `main`; `develop` previews are separate. Read the Docs configuration does not connect the external service.

<a id="gfl-015-015"></a>

## 015 · Coverage

Block ID: **GFL-015-015**.

All numbered guides are paired from inception, with no migration gaps. Entry points, config, requirements and assets are exempt. Keep both views aligned on status, constraints, limits and open decisions. Checks validate identities/pairing and build both views with warnings as errors.
