# Historical Django PoC adapter

`src/gramlot_django/` and `tests/` here preserve the extracted Django Page, ORM and demo implementation against the experimental `gramlot-poc` API. The root `examples/` and pre-native guides also describe that lane. These are evidence for future bounded ports, not importable native Gramlot 0.1.0 interfaces. They are excluded from the native wheel and from the current native test suite.
