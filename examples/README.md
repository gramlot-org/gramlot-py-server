# Microblog integration demo

Run `gramlot-flask` after installing the `demo` extra. The packaged example lives
in `src/gramlot_flask/_demo/pages/community.py`. It uses Python Gramlot declarations,
a shared dbSelect and bound remote Source to explore Microblog users and posts.
The original Microblog app is bundled under MIT; see its PROVENANCE.md and LICENSE.
No application checkout or runtime download is necessary.
